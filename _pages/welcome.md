### 2. Multi-Color Blackboard Drawing Robot — Chalkzilla (Academic Team Project)
- **Role:** Technical Project Lead & Software Systems Engineer (7-Person Team | Grade: 1.3)
- **Methodology:** Requirements Engineering, Concept Evaluation Matrix, V-Model
- **Project Management:** Clarified and finalized the requirements specification directly with the client. Developed a quantitative evaluation matrix to assess and select optimal concepts generated by the engineering team. Mapped the end-to-end system execution workflow process.
- **Software & Control Development:** Developed the complete software pipeline single-handedly. Built a Python tool to convert SVG/PNG vector images into G-code, and programmed an ESP32 microcontroller using Arduino C/C++ to translate G-code into low-level stepper motor pulse sequences.
- **Cross-Functional Integration:** Interfaced with mechanical and electronic sub-teams to ensure physical constraints matched software path-planning limits.

### 3. Machine Learning Systems Engineering (MATLAB)

#### **Case Study A: Air Quality Prediction (Time-Series Regression)**
- **Objective:** Predict the Air Quality Index (AQI) over time using data collected from multiple environmental sensors.
- **Feature Engineering:** Constructed a composite target index from available chemical measurements ($CO$, $NO_2$, $C_6H_6$) and temporal parameters (hour, day) to compensate for missing Ozone and $PM_{2.5}$ sensor channels.
- **Results:** Evaluated Linear Regression ($R^2 = 0.848$) against Random Forest ($R^2 = 0.859$), selecting the non-linear Random Forest approach to handle non-linear atmospheric interactions.

#### **Case Study B: Composite Damage Classification (CWT & Signal Processing)**
- **Objective:** Detect and classify structural damage types in Carbon Fiber Reinforced Plastic (CFRP) using Continuous Wavelet Transform (CWT) features.
- **Architecture Trade-offs:** Compared a 2-stage CNN architecture against single-stage deep learning and classical machine learning models.
- **Decision:** Selected a Random Forest model after it achieved 96.56% test accuracy (outperforming deep learning at 92.81%), optimizing for higher classification accuracy and lower computational load.
