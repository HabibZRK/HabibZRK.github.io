# Welcome to My Personal Website

🌐 Online at [zreik.me](https://zreik.me), also available at [habibzrk.github.io](https://habibzrk.github.io).

This repository contains the source code for my personal website.

## Serving Locally

Install the project dependencies and start the Jekyll development server:

```sh
bundle install
bundle exec jekyll serve
```

The website will be available at [http://localhost:4000](http://localhost:4000).

## Repository Information

This repository contains the source code for the personal website hosted at [zreik.me](https://zreik.me) and [habibzrk.github.io](https://habibzrk.github.io).


Commit messages begin with one of the following keywords. The keywords are
grouped according to whether the change is visible on the website.

### Website Changes

These keywords are used for changes that affect the website’s functionality,
content, appearance, or user experience:

- `feat`: new website features.
- `fix`: bug fixes or regressions affecting the website.
- `content`: website content updates.
- `style`: visual and stylistic changes.
- `refactor`: code restructuring that supports the website without changing its behavior.

### Repository and Metadata Changes

These keywords are used for changes that support the repository but do not
directly appear on the website:

- `ci`: continuous integration workflow changes.
- `chore`: repository maintenance or tooling updates.
- `cleanup`: removal of obsolete or unnecessary files and repository code.

For example, a content update uses the format `content: update the about page`,
while a CI configuration change uses `ci: update the workflow`.
